# PoxeyX1 Web Edition

Start from the project root using `npm start` or double-click the root `Launch PoxeyX1 Web.command`. Open http://127.0.0.1:8800/ . A static-file/Python server or opening index.html directly cannot run the isolated webpage runtime.

See the project-root README and reports/OPTIMIZATION-REPORT.md for current capabilities and limitations. Conversations is a truthful, unconnected interface preview in this recovery project. The full desktop game's catalog and AI backend were not in the supplied HTML/Lite archive.
